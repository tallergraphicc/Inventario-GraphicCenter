Rollos

Láminas

Láminas de 4×8 pies (48×96 pulg. = 32 pie²). En la salida pones las piezas que cortaste y el sistema descuenta ese pedazo de la lámina. Cuando a una lámina solo le quedan pedazos de menos de 12×12 pulg., se termina y lo que queda pasa a retazos.

Usuarios

Se entra al sistema con usuario, no con correo. El correo es opcional. Un usuario nunca se borra — se desactiva, para que el histórico siga diciendo quién hizo cada movimiento.
